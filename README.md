# Consultas-BD-Proyectos-educacionales

Repositorio académico con las actividades y proyectos educacionales desarrollados en la asignatura de **Consultas de Bases de Datos**. Reúne ejercicios prácticos de SQL, desde los fundamentos de la consulta y el uso de funciones, hasta contenidos de infraestructura en la nube y servicios de bases de datos en AWS. El material está organizado por semana para facilitar su revisión.
